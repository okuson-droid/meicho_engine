# Glossary — meicho_engine の用語集（詳細は `engine/GLOSSARY.md` が正本）

## 作業の単位・文書
- **便**: 引継ぎ書（`engine/HANDOFF_*.md`）1 通ぶんの作業。便 A（対抗の作り直し）・B（葉の多値化）・C（決定化の中身）・D（評価基盤）・E（学習の輪 2）・F（相手の型）・G（フェーズ 3〜5）・E-0（V_4' の交代判定）・M（診断の残り）・R（取り下げ）。
- **D-番号**: `engine/decisions.md` の設計判断。追記は「D-0xx 追記 n」。
- **LIT_NOTES / D065_NOTES / VALUE_BOOTSTRAP_NOTES**: 便ごとの報告の正本。
- **5 点セット**: マスターの PC で Rust を再ビルドしてもらう依頼の書き方（`REPORTING_RULES.md` §2.6）。
- **推し**: クロエが並べる選択肢のうち勧めるもの。マスターは原則すべて採用（D-069）。

## 測定
- **門番**: champion 交代の直接対決。固定 n=1,200（±0.028）または GSPRT。
- **錨**: H（ヒューリスティック）・貪欲・素 planner との勝率。差は局ごとに対にする。
- **対照 / null**: 同じ AI どうし・同じ帯。0.5 を含めば配線は健全。
- **帯 / next_free**: シード帯の台帳 `experiments/seed_bands.json`。kind は search / validate / diag など。学習帯で評価しない。
- **GSPRT**: ペンタノミアル逐次検定（シードペア＝同じシードで先後入替の 2 局が 1 観測）。「越えたか」だけに使い、大きさは固定 n で測る。
- **Wilson / CP**: n が小さい勝率の区間（対人局用）。
- **fingerprint**: 既定の挙動が不変であることの指紋 4 種。
- **ラダー core5**: 13 体の総当たり Elo。v9 が最新。Nash averaging の台は `planner_vc4cps` 1 体。
- **被搾取 / 透視カウンター（M7）**: AI の提出を見てから応手を選ぶ反則者に対する勝率（0.112）。
- **カンニング版 planner（M4）**: 相手の手札を見る測定専用の planner。`peek_` 始まり・登録簿に載せない。
- **M1〜M8**: 計画書 §2 の診断（M1 PIMC 三性質・M2 混合率・M3 楽観の分解・M4 天井・M5 曖昧さ解消率・M6 D1〜D3 循環と台・M7 透視・M8 JPC）。**便 M（D-076）で全部終わった。**
- **天井（M4）**: 相手の手札が完全に見えたときの強さの上限。カンニング版 対 champion **0.609 ±0.028 = Elo +77.1 [+57.2, +97.5]**（n=1,200）。実装で取れるのはこの一部。
- **カンニング逆説**: 決定化を真の手札に固定すると葉の価値の平均化が消え、V の較正が崩れて逆に弱くなりうる現象（第 2 集 §3.4）。**meicho では起きなかった。**
- **W_t / H_w**: 相手の手札としてありうる**区別できる多重集合**の数と、その多重度で重みづけたエントロピー（bit）。W の中央値 5,008・H_w の中央値 11.82 bit。
- **D_t（曖昧さ解消率）**: 1 − log W_t / log W_0。1 なら完全に確定、0 なら初めから絞れていない、**マイナスなら候補が増えている**。**中盤（⌈T/2⌉ ターン目）の中央値は 0.095**（閾値 0.30 を下回る＝便 B は急がない）。
- **lc / bias / df（M1 の三性質）**: lc は決着した最後の対抗の後知恵の詰み表で**全マス目の結果が同じ**割合（**0.105**。詰みの有無ではない）。bias は相関している局のうち席 0 が勝つ割合（0.571。ターンプレイヤーは 0.952）。df は D_t の縮み r_t と兼用。
- **hand_known**: スキャンで見て今も相手の手札にある札（`observe` が返す）。**探索（`_unseen` / `_determinize`）はこれを使っていない**＝決定の 29.2% で情報を捨てている（便 C の II-7 で直す）。

## AI の部品
- **champion**: `planner_vc4cps` ＝ 計画探索＋地平の延長＋葉 = V_4'＋相手モデル π₀（根だけ）＋選択フェイズ探索＋代打ち = 蒸留した小さい π。
- **V_1〜V_4'**: 反復ブートストラップの価値関数（`drl_sd001_vb1/vb2/vb3/vc4.json`）。
- **決定化**: 隠れ情報をエージェントの乱数で埋めた局面。`_determinize`（sorted してから混ぜる）。
- **lethal_uniform（lu50）**: 詰みが見えるときだけ相手を等重みに見るつまみ。champion にはしない。
- **T-14**: 対人局から抜いた回帰局面の検査。

## ゲーム
- **対抗**: 同時手番でカードを伏せて出すステップ。**協奏**: リソースの領域。**烈火・闘志・旋風** などはカード名。
- **SD001 / SD02**: 構築済みデッキ（カードプール）。共通カードは ID で 0 種。
