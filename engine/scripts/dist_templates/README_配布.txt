これは、カードゲーム『鳴潮：対決』（UCP・© KURO GAMES）のルールを
個人で再現した、非公式の対戦シミュレータです。AI と対戦できます。
UCP および KURO GAMES とは関係がなく、承認も受けていません。

【お願い】
- 無償で、個人で遊ぶためだけにお渡ししています。
- 他の人への再配布・アップロード・公開はしないでください。
- カードの画像や公式のカードテキストは含まれていません。
  カードは名前と数値と「エンジンの実装文」（プログラムがどう動くかの言い換え）で
  表示されます。実際のカードとは表記が異なることがあります。

【使い方】
1. MeichoSim.exe をダブルクリックする。
   黒い窓（コンソール）が開き、続けてブラウザが自動で開きます。
   開かないときは、ブラウザで http://127.0.0.1:8765 を開いてください。
2. 開始画面でデッキと相手を選び、「対局を始める」を押す。
3. 操作: 数字キー 1〜9 で手を選ぶ／クリックでも同じ／
   カードにマウスを乗せると拡大／Z で全カードの実装文を表示／L で合法手の一覧。
4. 対局が終わったら「記録して終了」を押す。
5. 終わるときは黒い窓を閉じる（または Ctrl-C）。

【記録】
対局の記録は、MeichoSim.exe と同じフォルダの results\human_games\ に
月ごとのファイル（例 2026-09.jsonl）で溜まります。中身はシードと手の列だけで、
個人情報は含みません。もしよければ、このファイルを作者に送ってください
（AI を強くする材料になります。送らなくても構いません）。

【動作環境】
Windows 10/11（64 ビット）。インストールは不要です。
初回起動時に Windows が「WindowsによってPCが保護されました」と出すことがあります。
「詳細情報」→「実行」で起動できます（署名を付けていないためです）。
ウイルス対策ソフトが警告する場合も同様で、内容は上記のとおり対戦プログラムだけです。

【通信】
このプログラムはインターネットに接続しません。ブラウザとの通信は
同じ PC の中（127.0.0.1）だけで行います。
