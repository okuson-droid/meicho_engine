### 3.1 便 A — 対抗の作り直し（対人 2 局の敗因に直接効く）

**目的**: 対抗ステップで AI が相手の応手を π₀ の argmax 1 手に決めつけ、詰みの烈火を持ってパス／青を選んだ形を直す。A-8（等重み混合）と A-9（決定化ごとの均衡 + δ）が不採用になった理由を踏まえ、**3 つの候補を同じ物差しで比べる**。

**含む提案**: II-1（π₀ argmax を分布に。上位 ε 同点ランダム化）、II-2（束ねた対抗ゲームのソルバ + 相手モデル信頼度 p）、II-10（ミニマックス後悔）。測定軸として II-3（透視カウンター = M7）。便 5 の B-3（`tau`）を吸収。

**候補**（すべて既定で無効のつまみとして実装し、既定の挙動と fingerprint 3 種は不変に保つ）:

| 候補 | 中身 | A-8・A-9 と何が違うか | 実装 |
|---|---|---|---|
| A-1 分布化 | 決定化 k ごとの相手の応手を π₀ の argmax ではなく π₀ の分布（温度 τ_opp、floor ε）で期待値化する。AI 側の僅差の手は上位 ε 同点ランダム化 | A-8 は**等重み**で混ぜた（π₀ を捨てた）。A-1 は π₀ の重みを使う | Python `_clash` + Rust `agents.rs`。数十行。回帰リスク最小 |
| A-2 束ねたソルバ + p | AI の提出分布 x を決定化 K 本に**共通**に置き、相手は決定化ごとに y_k。max_x Σ_k p_k min_{y_k} xᵀA_k y_k を RM+（または DCFR）200〜400 反復で解き、**平均戦略**を出す。p で π₀ 側（A-1 の評価）と最悪想定側を混合: p=1 で A-1 と一致 | A-9 は決定化**ごと**に解いて平均した（strategy fusion。自分が決定化ごとに手を変えられるという存在しない能力を仮定）。A-2 は共通の x を解く。δ ではなく p | Rust 新設モジュール（`clash_solver`）。150〜250 行 + Python の並行実装（真実源は Python）。V の呼び出しは行列を埋める 1 回だけ（最大 9×9×K） |
| A-3 ミニマックス後悔 | `_clash` の集約規則に「各列（相手の応手）での最良値との差の最大」を最小化する規則を加える。詰み表がそのまま後悔表になる（g001 で烈火を選ぶ） | A-8/A-9 とは決定基準そのものが違う。期待値でも最悪でもなく後悔 | Rust + Python。50 行 |

**手順**:

1. M2（混合率と利得幅）を先に測る。混合率 < 5% なら A-2 は作らず A-1 と A-3 だけで進める。
2. 3 候補を実装し、検査を先に書く（`tests/test_clash_lit.py`）。必須の検査: (a) 既定無効で fingerprint 3 種不変、(b) A-2 の p=1 が A-1 と同じ手を返す、(c) A-2 のソルバが小さな行列ゲーム（じゃんけん、3×3 の非対称）で LP 厳密解と可搾取度 < 10⁻³ で一致する、(d) 平均戦略を出していること（最終反復ではない）、(e) Python と Rust が同じ入力で同じ分布を返す（三者一致の型）。
3. 回帰局面 T-14 の 2 つで、各候補（A-2 は p ∈ {0.5, 0.75, 0.9}）が烈火を選ぶか。**通らない候補はここで落とす。**
4. 錨 3 種（H・貪欲・素 planner）各 n=600、全候補で**同じシード**（局ごとに対にして差を出す）。悪化（差の上端が 0 を下回る）した候補は落とす。

**完了の判定**: 3 候補の比較表（回帰局面／錨 3 種の対差／被搾取／門番／ラダー／対人局）が `LIT_NOTES.md` に揃い、裁定に出せること。交代の有無は問わない。

**転びやすいところ**: (1) 純均衡の罠——相手を強く見積もりすぎて詰みを逃す（A-9 の δ=0 で観測された）。p=0 を候補にしない。(2) 最終反復の戦略を出してしまう（RM+ は平均戦略で収束する。第 2 集 §1.6.5）。(3) 決定化ごとに解いてしまう（それは A-9 である。検査 (b)(c) で防ぐ）。(4) 錨の一部だけが悪化する形——A-8 で実際に起きた（H は +0.020 ±0.038 で悪化なし、貪欲 −0.053・素 planner −0.085 が悪化）。錨 3 種すべてを見る。

### 3.2 便 B — 葉の多値化（k=4 の継続戦略 + IIMC）

**目的**: 葉で V を 1 回呼ぶ設計を、「相手が 4 通りの打ち方（素 π₀・赤寄り・青寄り・パス寄り）で数ターン打った先」の V の min に変える。決定化を 6→12→24 に増やしても伸びない現象と、+0.17 の成分 3 に効く。

`measurement_discipline` のルール 1〜8 に、第 2 集から次を足す。

1. **n と 95% CI を必ず併記し、差は局ごとに対にする**（既存ルール 6・7）。候補間の比較も同じシードで回して対にする。
2. **調整用シード帯と評価用シード帯を分ける**（既存ルール 4・5）。p や ε や τ のような連続のつまみは、調整用帯で下見し、評価用帯で 1 回だけ測る。境界の結果は別帯で追試する（ルール 3）。
3. **V を門番の前に凍結し、ハッシュを manifest に記録する**。門番の対局で V を再学習しない（便 D-2）。
4. **GSPRT の母数（α、β、p₁、上限）は候補を見る前に固定して記録する**（便 D-4）。切り替え前後で 1 回は固定 n と併記する。
5. **回帰局面 T-14 を最初の関門にし、対人局で負けた対抗局面は T-14 に追加し続ける**。
6. **錨 3 種 + ラダー + 覗き見監査 0 + fingerprint**（D-034）。錨は「悪化していない」を差の区間で言う。一部の錨だけの悪化も落とす（A-8 では H は悪化せず、貪欲と素 planner が悪化した）。
7. **透視カウンター／LBR 型搾取者の列を報告に置く**（M7）。champion 候補や学習の相手には決してしない。
8. **根の較正誤差の欄を報告に置く**（便 D-6）。勝率で差が見えなくても較正誤差で見える。
9. **対人局は Wilson と Clopper-Pearson の両方**。極端な成功数では保守側（Clopper-Pearson）で判断する。対人局は判定ではなく診断に使う。
10. **すべての測定結果に champion の版とハッシュ、V / π のハッシュ、探索予算、engine、帯を刻む**（便 D-3）。champion を交代したら行列は測り直す。
11. **1 便で変える探索器の要素は 1 つ。** 便 A の候補はつまみとして並列に実装してよいが、交代の根拠にする組み合わせは 1 つに絞り、名前を変えて残す。
12. **費用は秒だけでなく局数でも記録する**（第 2 集 §8.5.5）。Rust 移植や並列化で速度が変わっても過去と比較できる。
13. **「論文でこう出た」を「この環境でこう出る」に変換する係数を毎回書く**（第 2 集 教訓 8）。Hearthstone の +12.2pp をそのまま期待しない。
