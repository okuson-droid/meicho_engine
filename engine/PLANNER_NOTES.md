## 中核: 深さではなく「採点の地点」

貪欲はアクションフェイズだけ担当させると 0.338 と最弱だった。原因は
先読みが浅いことではなく、**チャージを1手適用した直後を採点していた**ことである。
その局面では「手札が1枚減った」ことしか見えず、その協奏がこのターンの対抗で
何を撃てるようにしたかが評価に入らない。

利用する構造は §6.3 の2点。

1. アクションフェイズは**相手が関与しない単独逐次決定**である。
2. チャージ・切り替え・レベルアップは**各1ターン1回**に制限されている。

したがってターン内の行動列は高々3行動の順列であり、全列挙できる。
終端（`to_clash`）で対抗まで解決してから採点すれば、
「チャージしてから対抗に入る」の合計価値が正しく見える。

## 効いた順（アクションフェイズのみ計画探索・n=300）

| 構成 | 対 H_default |
|---|---|
| 1手貪欲（比較対象） | 0.338 |
| 計画探索 | 0.490 ±0.057 |
| ＋共通乱数 (CRN) | 0.550 ±0.056 |
| ＋決定化4通りの平均（既定構成での測定） | 0.617 ±0.055 |

### 分散抑制が半分を占めた

終端の対抗は固定方策の**混合戦略**で解決されるため、枝ごとに乱数列が違うと
その揺れがそのまま計画の優劣に化ける。対策は2段階。

- **共通乱数 (CRN)**: 各終端の直前に `fallback` の乱数状態を同じ点に戻し、
  全計画を同一の乱数の下で比べる。これだけで +0.06。
- **決定化の複数標本 (`plan_samples`)**: 決定化ごとに「その1手目から到達できる
  最良の計画の値」を取り、決定化をまたいで平均する（max-then-mean）。

`plan_samples` の掃引（既定構成・n=300）: 1→0.677, 2→0.710, 3→0.737,
**4→0.773**, 6→0.743。4以上は頭打ちでコストは線形なので、既定を 4 とした。

**これはこのプロジェクトで繰り返し出る教訓の3例目である。**
（1例目: CFRの部分ゲームの切り出し、2例目: 重みの単軸掃引、3例目: 探索の乱数の揺れ。
いずれも「測っているものが本当に見たいものか」を疑うと解けている。）

## A-3: 評価関数の重み × Params の結合最適化（CEM）

引継ぎ書 §7.6 の「重みを一つずつ掃引すると誤導する」への恒久対策。
`experiments/optimize_cem.py`。13次元（評価関数の重み5＋ヒューリスティックのParams8）を
交差エントロピー法で同時に探索した。8世代 × 個体12 × 各30局、個体の評価は
相手プール {H_default, X1, X2} への平均勝率。個体群平均は 0.632 → 0.895 に上がった。

### in-sample 化を仕組みで防いだ

| | 探索 | 検証 |
|---|---|---|
| シード帯 | 0..29（固定） | **10000..**（探索で一度も使っていない） |
| 相手 | H_default, X1, X2 | 上記＋ **X3・貪欲・調整前の計画探索** |

検証（n=150、未使用シード帯）:

| 相手 | 調整後 | 調整前 |
|---|---|---|
| H_default（探索プール） | 0.913 ±0.045 | 0.720 ±0.072 |
| X1（探索プール） | 0.907 ±0.047 | 0.747 ±0.070 |
| X2（探索プール） | 0.907 ±0.047 | 0.800 ±0.064 |
| **X3（未使用）** | **0.920 ±0.043** | 0.767 ±0.068 |
| **貪欲（未使用）** | **0.693 ±0.074** | 0.547 ±0.080 |
| **調整前の計画探索（未使用・直接対決）** | **0.660 ±0.076** | — |

探索に使わなかった相手でも、探索プール内と同じだけ改善している。
**過適合ではない**と判断してよい。

### 得られた重み（`TUNED_WEIGHTS` / `TUNED_PARAMS`）

| 項目 | 貪欲の既定（手調整） | CEM後 |
|---|---|---|
| w_concerto | 0.8 | 1.034 |
| w_hand | 0.5 | 1.126 |
| w_live_red | 0.4 | 0.533 |
| **w_level** | **0.0** | **0.498** |
| w_resource | 0.05 | 0.061 |
| own_color_weight | 12.0 | 10.373 |
| counter_weight | 0.0 | 0.722 |
| scarce_penalty | 0.35 | 0.255 |
| charge_min_hand | 2 | 1 |
| levelup_min_hand | 5 | 4 |
| pay_min_concerto | 3 | 2 |

**最も示唆的なのは `w_level` が 0.0 → 0.50 に反転したこと。**
1手先読みではレベルアップは「手札が減った」ようにしか見えず、
重み 1.0 で勝率 0.250 まで落ちた（GREEDY_NOTES.md）。ターン計画では
消費と効果を同じ視野に収めるため、正の重みが正しくなる。
**探索の構造が変われば、評価関数の正しい重みも変わる**という実例である。
`counter_weight` がわずかに正（0.72）に動いたのも同種の再検討対象だが、
own_color_weight 10.4 に対して小さく、旧結論（踏まない）を覆すほどではない。

再現: `python3 experiments/optimize_cem.py 8 12 30 2`（約1時間・2並列）。
結果は `experiments/cem_result.json` に世代ごとの履歴とともに保存される。

### A-4 後半: 13次元のうち意味があったのは3次元だけだった

調整済みの点で1軸ずつ ±σ 動かし、調整済み版と直接対決させて測った
（`experiments/param_sensitivity.py`、n=200、シード帯 30000..）。

| 軸 | −σ | +σ | 判定 |
|---|---|---|---|
| w_concerto | 0.420 ±0.068 | 0.480 ±0.069 | **効く** |
| w_hand | 0.425 ±0.069 | 0.450 ±0.069 | **効く** |
| w_resource | 0.580 ±0.068 | 0.425 ±0.069 | **効く**（→ 追試で否定、下記） |
| w_live_red | 0.485 | 0.490 | 平坦 |
| w_level | 0.495 | 0.510 | 平坦 |
| p_own_color / p_counter / p_scarce | — | — | 平坦（挙動は変わるが強さは変わらない） |
| p_concerto_tgt / p_charge_min / p_levelup_min / p_switch_gain | — | — | **完全な no-op** |
| p_pay_concerto | — | — | ほぼ no-op |

**基準の自己対戦は 0.515 ±0.069 である。** `p_concerto_tgt` などが両方向とも
きっかり 0.515 を返したのは、**1局も挙動が変わっていない**ことを意味する。

機構は明快で、これらはすべて**アクションフェイズ**の規則パラメータだが、
`PlannerAgent` はアクションフェイズを自分で計画する。fallback が呼ばれるのは
CHOICE・手札上限・相手モデル・ロールアウトだけなので、
**アクションフェイズの規則は一度も発火しない**。

したがって A-3 の CEM は、13次元のうち10次元が（ほぼ）無意味な方向だった状態で
探索していたことになる。次に再探索するときは **`w_*` の5次元に絞る**こと。
`p_*` は単体のヒューリスティックには大きく効くので（`HEURISTIC_NOTES.md` の
アブレーション参照）、**ヒューリスティック自身を調整するときは別に探索する**。

#### w_resource の「効く」は追試で消えた

−σ 側の 0.580 ±0.068（下限 0.512）は有意に見えたが、26回の比較の1つであり、
多重比較の偽陽性が疑わしい。**新しいシード帯（40000..）で n=500 の追試**を行った。

| w_resource | vs 調整済み(0.061) |
|---|---|
| −0.30 | 0.484 ±0.044 |
| **−0.14** | **0.534 ±0.044**（下限 0.490、0.5 を含む） |
| 0.00 | 0.470 ±0.044 |

再現しなかったので、既定値 0.061 は据え置く。
**26回の比較をすれば、CI 95% の境界付近は1〜2件出るのが当たり前である。**
境界の結果は必ず新しいシード帯で追試すること。

## 枝刈り

- チャージ対象は同一カードIDを畳んだうえ、`card_utility` の低い順に上位3枚。
- レベルアップは (スロット, カードID) で重複除去。
- 同一の結果局面に至る行動列は署名で重複除去する（順序交換の多くは可換）。
- `end_turn` は「対抗に出せる札が1枚もない」ときだけ終端候補にする。
  出せる札があるのに対抗に進まないのは §6.4(2)-1-A のもとでほぼ常に損だが、
  **これは枝刈りであって定理ではない**。反例が出たら外すこと。
- 終端採点の総数に上限（`leaf_budget`、既定220）を置く。

## 既知の簡略化・弱点

1. **レベルアップの手札コスト（discard）は枝にしていない。** `card_utility` で
   自動選択する。枝にすると手札枚数倍に増えるため（D-004 の方針）。
2. **終端の対抗を両者ともヒューリスティックで解決している。** 自分側は実戦では
   貪欲の決定化評価で選ぶので、`to_clash` の価値をやや過小評価する方向に偏る。
   自分側だけ `_clash` を使う版は未測定。
3. **相手モデルが固定ヒューリスティック**（貪欲と同じ制約）。異質な相手への
   見積もりは歪む。レビュー §6 B-3 / C-2 の課題。
4. 速度は約3.6局/秒（2並列・plan_samples=4）。ヒューリスティックの約1/70。
   フェーズ4の IS-MCTS ではこの探索をそのまま**行動抽象**
   （アクションフェイズを1ノードに潰す）として再利用する想定である。
