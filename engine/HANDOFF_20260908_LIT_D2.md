## 3. 手順（この順で）

### 3.1 D-4 ペンタノミアル GSPRT（`experiments/gate_sprt.py`・1 日）

**何を作るか**

- 入口は `champion_challenge_vb.py` と同じ: `--deck SD001 --challenger-json '{...}'`（現 champion への差分）と、検算のために `--base-json '{...}'`（基準側も差分で指定できる口。既定は現 champion）。`--seed0`・`--workers`・`--budget-sec`・`--out`。
- **母数は定数で持ち、結果 JSON に書く**: `ALPHA=0.025, BETA=0.10, P0=0.50, P1=0.55, MAX_GAMES=2400`。境界は `A = ln((1−β)/α) = ln(36) ≈ 3.584`（合格）、`B = ln(β/(1−α)) = ln(0.1/0.975) ≈ −2.277`（不合格）。**変える口は作らない**（変えるときは定数を変えて記録する）。
- **観測単位 = シードペア**: シード s で「挑戦者が先手」と「挑戦者が後手」の 2 局を回し、挑戦者の得点（勝ち 1・負け 0・引き分け 0.5）の和を 2 で割った **ペア得点 ∈ {0, 0.25, 0.5, 0.75, 1}** を 1 観測にする（引き分けは進行不能のみなので実質 {0, 0.5, 1} の三項だが、五項のまま実装する）。**`arena` の `series` は席を `seed % 2` で決めている**ので、「同じシードで両方の席」を回す口が要る（Rust `series_rs` に席を明示する引数があるか確かめ、無ければ `arena_rs` 側に `flip` を明示する薄い口を足す。**打ち方には触らない**）。
- **GSPRT の LLR**（fishtest の型・第 2 集 §7.2.2）: ペア得点の度数から、H₀（期待得点 p₀）と H₁（p₁）それぞれの**最尤の五項分布**を求め、その対数尤度の差を LLR とする。実装は「観測の度数 n_k と、平均を p に固定した最尤度数分布 q_k(p)」を求める標準の手順（p ごとに 1 次元の求根）。**単純化しない**（1 局ごとの二項 LLR に落とすと、ペアにした利得が消える）。
- **止め方**: 各ペアの後に LLR を更新し、`LLR ≥ A` で合格、`LLR ≤ B` で不合格、`2400 局` で判定不能（「境界」として報告）。**塊の途中では止めない**（塊の切れ目で判定する。塊は 20 ペア＝40 局）。
- **併記**: 同じ結果 JSON に、止まった時点の勝率と 95% 区間（Wilson）、**対応のある差の SE（不一致ペアだけ数える McNemar 型・第 2 集 §7.2.3 (d)）**、ペア得点の度数、止まった局数、所要時間、由来ブロック（開始時）。
- **再開**: D-068 の型。鍵は `{deck, base_diff, challenger_diff, seed0, params}`。**ペアの片方だけ回した状態では保存しない**（塊の切れ目＝ペアの切れ目）。

**検算 3 本**（回す前に「どちら側で止まるはず」を書く。**基準はすべて現 champion `planner_vc4cps`**・Rust・workers=2）

| # | 挑戦者 | 基準 | 予想 | 帯 |
|---|---|---|---|---|
| G1 弱い挑戦者 | 旧 champion `planner_vb3cps` の spec（`value_net` を `drl_sd001_vb3.json` に） | 現 champion | 便 E-0 の逆向き（p ≈ 0.43）→ **不合格側で早く止まる**（第 2 集の目安: p=0.40 で約 107 局。実測で置き換える） | 666000.. |
| G2 強い挑戦者 | 現 champion | **`--base-json` で旧 champion** | 便 E-0 と同じ向き（p ≈ 0.57）→ **合格側で止まる**（目安: p=0.55 で約 640 局・0.60 で約 241 局） | 667200.. |
| G3 対照 | 現 champion | 現 champion | p = 0.5 → **不合格側か上限**（合格したら検定が壊れている。α=0.025 なので 40 回に 1 回は起きうる——起きたら別の帯でもう 1 回） | 668400.. |

各本について、**同じ帯で固定 n=1,200 を `champion_challenge_vb.py` の直接対決と同じ型で回した値**（勝率 ±CI）を併記する（G1・G2 は GSPRT が止まった局数より多く回ることになる。これが「切り替え前後で 1 回は両方式を併記」）。固定 n の 1,200 局は 1 本あたり約 46 分（D-072 の 1 時間の内側）。**先に GSPRT を 3 本、次に固定 n を 3 本**の順。

### 3.2 D-5 ラダー解析（`experiments/ladder_analysis.py`・1〜2 日・対局なし）

**入力**: `results/ladder.json` の記録（`--index -1` 既定＝最新 v9。`--index -2` で v8）。勝率行列 p_ij と局数 n_ij を組から作る。

**出すもの**（第 2 集 §7.5.5 (iii-a)〜(iii-d) と §7.4.1）:

1. **Nash averaging**: 反対称ロジット行列 A_ij = log(p_ij/(1−p_ij))（p を [ε, 1−ε] に切る。ε=1/(2n_ij)）。この行列を利得とする 2 人ゼロ和ゲームの**最大エントロピー Nash** p* と、各体の nA_i = (A p*)_i。実装は純 numpy で（LP 用の scipy は作業環境に入れてよいが、**マスターの PC に無くても動く**こと）: 対称ゼロ和なので regret matching／fictitious play の平均戦略で近似し、複数の初期値から得た解の平均で最大エントロピー側に寄せる。**検査は答えの分かる行列で**（推移的 3 体 → 台は最強の 1 体・じゃんけん 3 体 → 一様・じゃんけん＋複製 → (1/3, 1/3, 1/6, 1/6) と A・B の nA が不変＝論文の P1）。
2. **台に乗っているか・nA ≥ 0 か**: 新 champion `planner_vc4cps` について明記。**Elo 1 位は補助指標**として並べる。
3. **3 巡回の数**: 「i が j に勝率 τ 以上」を辺として、τ = 0.6（AlphaStar は 0.7。10 体級では厳しすぎるので 0.6 から）・0.55・0.7 の 3 段で数える。既存の `rating.find_cycles` と定義を揃えるか、違いを書く。
4. **mElo₂ と Elo の当てはまり比較**: 各組の対局を学習用／検証用に分け（組ごとに局を半々。乱数は固定）、Elo（1 次元）と mElo₂（Elo＋2 次元の巡回成分）を学習用で当て、検証用の対数損失を比べる。**mElo₂ が明確に良ければ「1 次元では表せない」**。実装は勾配降下（学習率と反復回数を結果に書く）。
5. **有効多様性**: Nash の台の上で、Σ_ij p*_i p*_j |A_ij|₊（第 2 集 §5.2.1 の定義に合わせる。定義の式を結果に書く）。**台のサイズ（D2）と有効多様性（D3）を M6 の答えとして報告する**（台が 1〜2 体ならリーグは不要、が計画書 §2 の分岐）。
6. **先手の利**（BayesElo の eloAdvantage 相当）: ラダーの組は席ごとの勝敗を記録していない。**席が分かる対局**から出す——`results/vb/d065_null_lit_a.json` の対照 1,200 局（champion 同士・席は seed の偶奇）で「席 0 の勝率」を区間つきで。ほかに席つきの記録があれば足す。**今後のラダーは組ごとに席別の勝敗を記録する**（`ladder.py` の `rec` に `wins_a_seat0` / `wins_a_seat1` を足す。既存の鍵は変えない。次にラダーを回したときから入る）。
7. **v8 への遡及適用**: 同じ道具を v8 の記録に当て、台・nA・3 巡回が v8→v9 でどう動いたかを並べる（Nash の分布は不連続に飛びうるので、**単一世代でなく 2 世代の安定性**を見る）。
8. WHR（champion 系譜）は**本便ではやらない**（ラダーの 13 体は凍結されているので時間変化のモデルは不要。系譜の履歴に使うのは後日）。

**出力**: `results/ladder_analysis_core5_v9.json` と `.md`（v8 も同様）。`.md` には各指標の一行の意味（マスター向け）と、**D-034 の条件 (iii) をどう書き換える案か**（判断が要る点・§6）。

## 7. 転びやすいところ

1. **1 局ごとの二項 LLR で作ってしまう** → ペアにした利得が消える。五項の最尤度数で作る（T-D2-1 で符号と大きさを固定）。
2. **ペアの片方だけ回った途中経過を数える** → 塊の切れ目をペアの切れ目にする。
3. **G3（対照）が合格側で止まる** → α=0.025 なので 40 回に 1 回は起きる。別の帯でもう 1 回。2 回続けて合格なら検定が壊れている（LLR の向き・p の定義）。
4. **Nash の解が初期値で変わる** → 反対称行列の最大エントロピー Nash は一意（論文の定理）。複数の初期値の平均戦略が同じところに収束することを確かめ、収束の反復数と誤差を結果に書く。
5. **mElo₂ が過学習する** → 検証用の対数損失で比べる（学習用で比べない）。
6. **先手の利をラダーの組から出そうとする** → 席の記録が無い。席が分かる対局（対照 1,200 局）から出し、ラダーには席別の記録を足して次回から。
7. **再生の値が記録と合わない** → 決定化の乱数の違い。記録側を正とし差を書く。合わせようとして乱数の消費順を変えない。
8. **負けた局面を T-14 に足したくなる** → 詰み表で詰みが無い対抗は足さない。
9. **配布版の便（D-074）と同じファイルを触る** → `webapp/record.py` などは書き戻す前に mtime を見比べる。
