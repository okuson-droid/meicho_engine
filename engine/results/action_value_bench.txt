== 行動の価値を勝率差で直接測る（D-039）==
シード帯 120000.. / 試行 400 / 有効な対 400

分岐点: 平均ターン 4.0 / そこで計画探索が実際にレベルアップを選んだ割合 13.5%

枝                                               勝率
A: 今レベルアップする                     0.877 ±0.032 (n=400)
B: 今はレベルアップしない                   0.890 ±0.031 (n=400)

対応のある比較（同じ分岐点から両方走らせた 400 対）:
  同じ結果になった対: 339 (84.8%)
  A だけ勝った: 28 / B だけ勝った: 33
  **勝率差 (A − B) = -0.013**
  95% 区間 [-0.050, +0.025]  → 0 を含むので差があるとは言えない

ターン帯別の内訳（A − B の勝率差）:
       ターン     対の数      Aの勝率      Bの勝率        差
       1-2     106     0.906     0.896   +0.009
       3-4     125     0.848     0.904   -0.056
       5-6     126     0.881     0.865   +0.016
       7-9      43     0.884     0.907   -0.023

【解釈の手引き】
  差がプラス = 今レベルアップした方が勝ちやすい（現行評価関数 +0.498 を支持）
  差がマイナス = 今はやらない方が勝ちやすい（学習した重み −0.197 を支持）

  差が 0 付近 = この構成ではレベルアップはほぼ無関係だった
