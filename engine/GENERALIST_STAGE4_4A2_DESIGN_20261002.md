- **H と貪欲のブロック**: G@1,000 0.98・0.95／S@1,000 0.955・0.955／R@1,000 0.95・0.8975。どの候補も張り付いている
- **素 planner のブロック**:
  - G: @0 0.625（200 局）→ @300 0.62（200 局）→ @1,000 0.6225（400 局）。ほとんど動かない
  - S: @0 0.255 → @300 0.51 → @1,000 0.6375。G の高さで止まった
  - R: @300 0.32 → @1,000 0.595

### 1.3 天井の仮説（未検証）

素 planner のブロックで、三者とも 0.60〜0.64 に寄っていく。G は教材 0 局ですでにそこにいて、追加学習で動かない。S と R は下から上がってきて、そこで止まりかけている。「netfree の教材から学べる上限がこのあたりにある」という仮説と合う。段階3 で「V_0 を葉にした教師の教材に、V_0 を超える信号が無かった」（3-a・T-0・T-b・(c)・D-146〜D-150）こととも同じ形である。

**ただし、別の説明も同じ数字と合う**: (i) G は汎用の初期値が強すぎて、1,000 局の教材では動かない（G に固有の性質）／(ii) S は 1,000 局ではまだ伸び切っていない（教材を増やせば G を越える）。問い 1 はこの 2 つを分ける。(ii) なら S は 3,000 局で上がり、天井の仮説は退く。

### 1.4 なぜ S で測るか

天井の有無を見るには「まだ上がっている学び手」に教材を足すのがいちばん感度が高い。G は 0 → 1,000 局で動かなかったので、G に教材を足して動かなくても、天井なのか G の性質なのかを分けられない。S は 300 → 1,000 局で +0.13 上がった（素 planner）ので、1,000 → 3,000 局で止まれば天井を、上がり続ければ天井ではないことを示す。

## 4. 問い 1 と問い 2（回す前に固定）

### 4.1 問い 1 の学び直し

- 教材: 4-A の 1,000 局（861000..861999）＋新しい 2,000 局（880000..881999）＝ **3,000 局**。新しい 2,000 局は 4-A と同じ生成器・同じ配分（ミラー 40%・異種 16 × 2.4%・錨 3 × 7.2%。ブロックあたりミラー 800・異種 48・錨 144）。4-A の 1,000 局は 3,000 局に**入れ子**で含まれる
- 検証の記録: 4-A のもの（863000..863203・204 局）のまま
- 学び方: 4-A の S@1,000 と**まったく同じ引数**（`--init s4S_sK.json`・6 エポック・幹 256 × 2・π 頭 128・学習率 1e-3・バッチ 1,024・`--lam 0.7`・`--vtarget max`・`--calib-scale bulk`・`--calib-form linear`・`--select best_v`・`--threads 2`・乱数 0・1・2）。違うのは `--train` に新しい記録を足すことだけ。3 本を `ensemble_net.py` で束ねて S@3,000
- 見る決定の数について: エポック数が同じなので、S@3,000 は S@1,000 の約 3 倍の更新を受ける。4-A の S@1,000 は 3 本とも 1〜3 エポック目が最良で、6 エポックを使い切っていなかった（更新の回数が足りなかったわけではない）ので、本書ではエポックをそろえる（G-1 のように決定数をそろえる直しはしない）。選んだエポックは報告する
- 4-A の S@1,000（sha `20ea5045e5eb32cb`）が容器に残っていればそれを使う。無ければ §8.1 の規則で作り直す

### 4.2 問い 1 の評価

- 課題: 4-A と同じ `eval_s2_repr.py --task s4 --target ENV_SANGE_RM_TSUBAKI`（候補も相手も対象デッキのミラー・候補は `NETFREE`＋葉の V・τ = 0）
- **主比較の局: 素 planner のブロックだけ、1,600 局（883000..884599）。S@3,000 と S@1,000 で同じシード**
- 添える局（判定に使わない）:
  - G@0（V_0・`s2v_id_ens3`・sha `2d4504e2125bc244`）と netfree（V なし）の素 planner のブロック 400 局（883000..883399）。「天井の高さ」と「V が教師の上にどれだけ足しているか」を見るため
  - S@3,000 の H・貪欲のブロック 各 200 局（883000..883199）。張り付いたまま崩れていないかを見る

### 4.3 局数の根拠（`eval_4a.json` から計算）

- 4-A の素 planner のブロック 400 局で、2 局の組を単位にした候補どうしの得点差の標準偏差は 0.43〜0.47（S − G 0.473・S − R 0.431・G − R 0.460）。同じシードどうしの相関は 0.06〜0.12 と小さく、対にしても区間はあまり狭まらない
- 組の差の標準偏差を 0.45 と置くと、95% 区間の半幅は 1,200 局で約 0.036、**1,600 局で約 0.031**、2,000 局で約 0.028
- §4.4 の規則で、本当の差が 0 のときに「天井を支持」と出る確率は 1,200 局で約 78%・1,600 局で約 88%・2,000 局で約 94%。本当の差が +0.13（直前と同じ伸び）のときに「天井ではない」と出る確率は、どの局数でもほぼ 100%。費用との釣り合いで 1,600 局を取る

### 4.4 問い 1 の判定（回す前に固定）

- **主比較: D1 = S@3,000 − S@1,000（素 planner のブロック・1,600 局）**。局ごとに対・組（2 局）を単位に 10,000 回再標本化した 95% 区間（`eval_s2_repr.py report`）
- 判定は 4 つ:
  - **上端 < +0.05 かつ 下端 ≤ 0 →「天井を支持」**
  - **下端 > 0 かつ 上端 < +0.05 →「天井に近い」**（上がるが小さい）
  - **下端 > 0 かつ 上端 ≥ +0.05 →「天井ではない」**
  - **それ以外（下端 ≤ 0 かつ 上端 ≥ +0.05）→「決まらない」**
- 境界の追試はしない（通るまで追試しない・計画書 §7.3）
- +0.05 の根拠: S は 300 → 1,000 局（約 3.3 倍）で素 planner が +0.1275 上がった（0.51 → 0.6375）。1,000 → 3,000 局（3 倍）でその 4 割未満しか上がらないなら、学び手がまだ上がっている途中にもかかわらず教材の効き目が大きく落ちたと言える。対数の目盛りで伸びが続く場合（約 +0.13）とははっきり分かれる
- 添える（判定に使わない）: 各候補の素 planner の得点と区間・S@3,000 − G@0（400 局の部分）・G@0 − netfree（400 局）・S@3,000 の H・貪欲の得点・部品 3 本の検証 v_logloss と選んだエポック・教師 p の広がり（**0.05 未満なら止める**）
- 読み方の注意: 「天井を支持」は「netfree の教材をこの量の範囲で増やしても、S はこの対象デッキで上がらない」までである。V の形・学び方・別のデッキで同じかは言わない（§10）

### 4.5 問い 2 の評価

- 課題: `eval_s2_repr.py --task s4 --opponents planner --target <デッキ>` を、残りの調整デッキ 3 つ（`ENV_SANGE_RF_TSUBAKI`・`ENV_YANG_RF_TSUBAKI`・`ENV_YANG_RM_TSUBAKI`）でそれぞれ回す。候補も相手もそのデッキのミラー

- 局: 各デッキ 400 局（885000..885399・3 デッキ・2 候補で同じシード）。計 2,400 局

### 4.6 問い 2 の判定（回す前に固定）

- **主比較: D2 = G@0 − S@0 を、デッキごとに 1 本ずつ（3 本）**。区間は 1 − 0.05/3 ＝ **98.3%**（組を単位に 10,000 回再標本化・`report --level 0.983`）

## 10. 言えないこと

- 問い 1 は 1 つの対象デッキ・1 つの教師（netfree）・1 つの網の形での結果である。「天井を支持」でも、別のデッキや別の網、別の学び方で同じかは言えない
- 「天井を支持」は「教材の量を増やしても上がらない」までで、**天井の原因**（教師のラベルの質か、V の入力の欠落か、評価の相手が素 planner であることか）は分けない
- 天井の高さ（素 planner で 0.60〜0.64）は、素 planner という 1 つの相手に対する得点である。強さそのものの上限ではない
- 問い 1 で S@3,000 が上がっても、それが「教材の量」か「更新の回数」（エポックをそろえたので約 3 倍）かは区別しない（§4.1）
- 問い 2 の調整デッキ 3 つは、段階2 の表現の比較と段階3 の選択・診断に使った。V_0（G@0）はこれらのデッキでの成績も見て選ばれているので、G に有利な選択の偏りが少し入りうる。S にはこの偏りが無い
- 調整デッキ 4 つはすべてツバキのグループ 3 で、打ち方の幅が狭い。問い 2 の「別のデッキでも出る」はこの 4 つの中での話である
- 4-D の対局は局数が少なく、採否には使わない
