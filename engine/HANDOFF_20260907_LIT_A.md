## 3. 設計

### 3.1 つまみ `lethal_uniform`（θ・既定 0.0）— 「詰みが見えるときだけ、相手を等重みに見る」

**考え方**: 2026-09-03 の 2 局で AI が負けたのは、詰みを取れる烈火を持ちながら、π₀（自分の写し）が「相手は必ず青で受ける」と読んだからである。`opp_mix=1.0`（相手を等重みに見る）はこれを直すが、**普段の対抗の 4 回に 1 回**を変え、π₀ どおりに受けてくる相手（素の計画探索）には損をする。そこで**広げる場面を絞る**: 「自分の合法手のどれかが、相手の合法手のかなりの割合に対して詰みになる」ときだけ等重みに切り替え、それ以外は現行どおり π₀ の最尤 1 手で評価する。詰みの無い対抗では**挙動は 1 ビットも変わらない**。

**定義**（決定化 t ごと。`_clash` の中）:

1. `cols` = その決定化での相手の合法手（`legal_actions(t, 1−pi)`。空なら `[opp_act]`）。`k = len(cols)`。
2. 行列 `m[i][j] = _score_clash(t, pi, acts[i], cols[j], goal)`（CRN を毎回復元。`nash_delta` の経路と同じ組み立て）。
3. `lethal_frac[i] += (m[i][j] ≥ 1.0 − 1e-9 である j の数) / k`。`_score_clash` は決着済みの局面で厳密に 1.0 を返す（`planner._eval` の規約）ので、これが「その手で相手のライフを 0 にできた列の割合」になる。
4. `totals_pi0[i] += m[i][j*]`（`j*` は `opp_act` の列。現行の値）。`totals_uni[i] += Σ_j m[i][j] / k`（等重みの値）。
5. 全決定化を足したあと、`lethal_frac[i] /= samples`。**`max_i lethal_frac[i] ≥ θ` なら `totals_uni` で選ぶ（`_pick`）。そうでなければ `totals_pi0` で選ぶ。**

- `last_clash` に `"rule": "uniform" | "pi0"` と `"lethal_frac": [...]` を足す（便 D-7 で入れた `ai_clash` に載る。対人局で「切り替わった対抗」が後から分かる）。
- `tau`（確率化）との併用は可（`_pick` の中で従来どおり）。`opp_mix` / `nash_delta` との併用は `ValueError`。
- `reeval_samples`（取り直し）は `clash_totals` を 1 手だけで呼び直す既存の形のまま。`lethal_uniform` の取り直しは、選んだ規則（uniform / pi0）と同じ規則で 1 手を評価する（Rust の `clash` の `reeval` 分岐を見ること）。
- **費用**: 行列を全部埋めるので対抗の決定が 5〜8 倍（A-8 と同じ）。対抗は決定の 1〜2 割なので全体で 1 割未満の増加（A-9 の実測と同程度）。**実測して報告する。**

**Rust**: `rust/src/agents.rs` の `clash_totals` に `lethal_uniform > 0.0` の分岐を足す（`nash_delta` の分岐のすぐ後ろ）。行列の列順・足す順・`1.0 − 1e-9` の閾値を Python と同じにする。`lib.rs` の `PyPlanner` の引数（既定 0.0）と `features()` の札（`"lethal_uniform"`）を足す。**Python と Rust の毎手一致**は §5 T-A2 で固定する。

### 4.3 錨 3 種（Rust・同シード対・600 対）

`probe_d065.py --cand <名前> --n-anchor 600`（`--skip-gate` で錨だけ先に）。帯は §6 の共通帯（H +1300／貪欲 +1900／素planner +2500・各 600）。**全候補で同じシード**なので、候補どうしの差も対にできる。判定は「差の区間が 0 をまたぐ＝悪化なし」。**1 種でも上端が 0 を下回れば「悪化」**（A-8 では貪欲と素planner が悪化した）。1 候補 1,800 局 ≈ 35 分（1.09 秒/局＋1 割）。

### 4.4 被搾取（Python・透視カウンター・同シード 300 局）

## 7. 判定と交代

### 7.1 採用基準（D-069(1)）

候補を採るのは次のすべてを満たすとき。

1. T-14 を 2 局面とも通る。
2. 詰み見逃し率が champion より**悪化していない**（同シード・差の区間が 0 をまたぐか上）。
