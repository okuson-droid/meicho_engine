# E-1 葉の採点を両視点の平均にする（D-177）（2026-10-21〜・クラウドの Claude Code）

D-177 §5 の順序（P-0 → P-1 → **E-1** → 分岐）の 3 本目。中身は読みの報告 `engine/GENERALIST_WALL_READING_20261020.md` §7 の E-1、物差しは設計書 `engine/GENERALIST_STAGE4_SUMMARY_DESIGN_20261020.md` §5.2 の M-1〜M-8 である。機械 `cc-cloud-4`。champion・既定の打ち方・符号化は変えていない。最終評価の 4 デッキは開いていない。

## 結論

- **E-1 は +2% 以上の改善を否定して閉じる**（確かめ・95%）
  - 足し継ぎ（回 1〜2・5,632 局）では「候補」だった: +0.0167 [+0.0034, +0.0293]
  - 新しい帯での 1 回だけの確かめ（6,784 局）: 両視点 − 従来 = **+0.0019 [−0.0100, +0.0140]**
  - 確かめで否定されたので、事前登録 §0.4 により候補を閉じる。錨は「伸びた」ときだけ添えるものなので回さなかった
- 読みの報告 §7 の分岐により、**葉の当てはまりは壁の正体ではない**と読む。腕 D を飛ばして **E-2（`bundle_p`）** へ進む
- null（配線の確かめ）は 2 本とも 0.5 を含む。調整デッキ 16 ブロックの種類のまとめも 0.5 を含む（M-6）
- 足し継ぎの「候補」が確かめで消えたのは、腕 C（D-174・D-175）と同じ形である。二段構え（M-3）が働いた

## 3. 読み方（判定には使わない）

- 探索の点推定 +0.0167 と確かめの +0.0019 の差は、確かめの区間（幅 ±0.012）の外にある
  - 探索で下端が 0 を越えたのは、2 回のぞいたうちの 1 回の振れと読める
  - 「何度も見ると下端 > 0 が偶然出る」という、M-3 が備えた形そのものである
- 読みの報告 §4 の「両視点の平均は葉の対数損失を V_0 → V_1 以上に下げる」と合わせると、次のように読める
  - 葉の当てはまりを学習なしで上げても、直接対決の強さは +2% 以上は動かない
  - V_1（D-171）と同じく、「当てはまりは良くなるが強くならない」の 2 例目である
- 両視点は葉の V の呼び出しが 2 倍になる。挑戦と基準が同じ局で打つので、1 手あたりの時間は分けて測っていない
