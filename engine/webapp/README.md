# 対人検証アプリ（段階1）

設計書は `../APP_DESIGN.md`（v3）と、**画面については `../UI_DESIGN.md`（v1.1・D-063）**。
本書は**使い方**だけを書く。

## 起動

```
cd engine
python3 -m webapp.server
```

ブラウザが自動で開く。開かなければ `http://127.0.0.1:8765` を手で開く。

**開始画面でデッキ（SD001 / SD02）と相手を選ぶ。**
デッキごとに強さは別物なので、**記録には必ずどちらで打ったかが残る**。
勝率を出すときに SD001 と SD02 を混ぜてはならない。
終了は起動したターミナルで Ctrl-C。

- 依存は**標準ライブラリのみ**（Flask 等は不要）
- **127.0.0.1 にしか結び付かない**。外部からは見えない
- ブラウザが勝手に開くのが邪魔なら `--no-browser`、ポートを変えるなら `--port 9000`

## 操作

| 操作 | 効果 |
|---|---|
| **1〜9** | その番号の行動を選ぶ |
| **↑ ↓ と Enter** | 10 個以上あるときに選ぶ |
| クリック | 同じ |
| **C** | 「自分のキャラデッキ」欄を開閉する |
| **F** | 直前の CPU の手に「気になる」印を付ける（対局は止まらない） |
| **種類のボタン** | まず「何をするか」を選ぶ（チャージ／レベルアップ／切り替え…） |
| **カードをクリック** | その種類の**対象**を選ぶ。黄色く縁取られた札が対象 |
| **Esc** | 対象選びをやめる／モーダルを閉じる |
| **L** | 合法手をそのまま並べた一覧を開閉する（安全網） |
| **トラッシュ 🔍** | トラッシュの中身を出す（**両者とも公開情報**） |
| **カードにマウスを乗せる** | 拡大する（実卓で手に取る代わり）。**左が画像・右がエンジンの実装文** |
| **カードから離す** | 拡大が消える。**出るのは乗せている間だけ** |
| **Z** | エンジンの実装文を全カードの下に出す／隠す |
| **+ / −** | カードの大きさを変える |

拡大は**マウスで乗せている間だけ**出る。留め置きも、キーボードからの自動表示もしない
（盤面が覆われて読めなくなるため。D-063 v2）。キーボードだけで打つときは `Z` を使うとよい。
大きさと Z の状態はブラウザに覚えさせている（**記録には一切入らない**）。

**マリガンだけ操作が違う。** 戻す枚数の組み合わせは初手 5 枚で 32 通りあり、
一覧に並べると読めない。そこで**カードごとに戻す／残すを選ぶ画面**にした。

| マリガン中の操作 | 効果 |
|---|---|
| **1〜9**／クリック | そのカードの「戻す」を入切する（もう一度押すと戻る） |
| **Enter** | 選んだ組み合わせで決定 |
| 「1枚も戻さない」 | そのまま確定 |

- 合法手が 1 つしかない場面は**自動で進む**（ログに「（自動）」と残る）
- 「投了」だけ確認を出す（取り返しがつかないため）
- 対局が終わったら **「記録して終了」** を押す。押した時点で保存され、
  **その場で記録を再生して一致するかを確かめる**（食い違えば警告が出る）

## ログの見かた（D-063 v4）

トラッシュに置かれた札は、**どこから来たか**を書き分ける。連撃や対抗では
コストに払った札と使った札が同じトラッシュに並ぶので、これが無いと読めない。

| 書き方 | 意味 |
|---|---|
| **をコストとして支払った**（協奏エリア → トラッシュ） | コストの支払い |
| **が使い終わってトラッシュへ**（アクションエリア → トラッシュ） | 実際に使った札 |
| を手札から捨てた | 捨て札（手札コスト・手札上限） |
| を手札から場に出した | 対抗の提出・連撃 |
| を手札から協奏エリアへ（チャージ） | チャージ |
| がデッキから協奏エリアへ | 効果でデッキの上から置かれた |

出どころは観測の差分から引いている。**相手の手札は写らないので、
枚数が減っていなければ「手札から」とは書かない。**

## 画面の見かた

- **上段が CPU、下段があなた。** 数値は前の局面からの差分を ▲▼ で示す
- **カードは実カードの画像で並ぶ。** 色は左端の帯で分かる。
  細かい数値と文面は**拡大して読む**（マウスを乗せる／Z で全部出す）
- **相手の手札は裏面が枚数ぶん並ぶ。** 中身は見えない（観測に無い）。
  山札は厚みのある 1 枚に残り枚数を重ねてある
- **画像が無いカードは赤い破線の枠になり、文字表示に落ちる。**
  その枚数は開始画面と上のバーに出る（黙って消えることはない）
- **キャラ枠には、重ねた下のカードのスキルも全部出す**（下のスキルも有効・§6.3-3）
- 「自分のキャラデッキ」欄に**キャラデッキ全体**（場に出た分を含む）を出す。
  **★ が付いた札は今レベルアップできる**（エンジンの合法手から引いている）
- スキャン等で相手の手札を確認したら、CPU 側に**「判明した手札」欄**（青枠）が出る。
  推測ではなく確定情報である。相手が使った分は自動で消える。
  確認した瞬間はログに `◇` で残る
- 左中央の枠に**継続効果と対抗の履歴**（旋風のコスト+1、連撃禁止など）
- 黒い枠が**ログ**。◆ が対抗の結果、★ が印、■ が異常
- 「使用済: チャージ☑ 切替□ Lv□」で 1 ターン 1 回の行動の消化状況が分かる

### スキルの文面について（最重要）

画面に出るスキル文は**カードテキストの転記ではない**。
**エンジンが実装しているオペコード列を日本語に言い換えたもの**である。
検証アプリとしてはこちらが正しい。「カードにこう書いてある」ではなく
「エンジンはこう動かす」が見えるので、**実装とテキストの食い違いを見つけられる**。

**カードを拡大したとき、左の画像が「カードにこう書いてある」、
右の文が「エンジンはこう動かす」である。** この 2 つを読み比べるのが検証の本体。
食い違っていたら F キーで印を付けてほしい。

**対局中に見えるのは `observe()` が返す情報だけ**である。
つまり **CPU に見えている情報と完全に同じ**であり、相手の手札も山札も見えない。
相手のキャラデッキも見えない（ルール上も裏向き・§5-2）。
（対局後に全情報で振り返る機能は段階2で作る。）

## 記録

- `results/human_games/YYYY-MM.jsonl` に 1 局 1 行で追記される
- 中身は**シードと全行動列**だけ。盤面は保存しない
  （エンジンが決定的なので、再生すれば完全に復元できる。§6.1）
- **AI の実装が将来変わっても、古い記録はそのまま再生できる**
  （再生は記録された行動を流すだけで AI を使わない）
- シード帯 **130000..139999** を使う（`experiments/seed_bands.json` に登録済み）。
  起動時に既存の記録を読み、続きのシードから始める
- **AI の対抗の行には `ai_clash` が付く**（2026-09-07・D-7）。中身は
  `{"acts": [候補の表示名], "totals": [決定化 1 本あたりの点数], "chosen": 選んだ添字}`。
  「AI が何を迷って、どれを選んだか」の記録であり、マスターが実際に何を出したかと
  突き合わせて相手の型を作るための材料である（便 F）。人間の行には付かない
- **欄が 1 つ増えただけなので `app_version` は上げていない**。再生は `action` しか
  読まないので、`ai_clash` が無い古い記録もそのまま読める（`tests/test_lit_d.py` T-L4）

## 配布版（D-074・2026-09-08）

知人に配る版は、開発ツリーをそのまま渡すのではなく `scripts/make_dist.py` が **allowlist で組み立てた別フォルダ**である。
実カード画像（`cards/`）・公式カード文の転記（`cards_structured.*`）・マスターの棋譜（`results/human_games/`）・
内部文書は**構造的に入らない**（`tests/test_dist.py` が固定）。

- 組み立て・検査・煙テスト: `python3 scripts/make_dist.py --smoke`（作業環境でも回る）
- Windows 実行ファイルまで: `py -3.11 scripts\make_dist.py --smoke --exe --out C:\meicho_dist\dist_src`（マスターの PC。手順は `HANDOFF_20260908_DIST.md`）
- 配布モードは **実行ファイル（または `run_app.py`）の隣に `dist.json` があるときだけ**効く（`webapp/distribution.py`）。
  開発ツリーには `dist.json` を置かないので、開発中のアプリは従来どおり。
- 配布モードで変わるのは 3 点: 記録の置き場が実行ファイルの隣の `results/` になる／相手の一覧が `dist.json` の allowlist で絞られ表示名が言い換わる／
  画面に名前・注意書き・権利表記が出て、画像が無いことは警告でなく説明になる。
