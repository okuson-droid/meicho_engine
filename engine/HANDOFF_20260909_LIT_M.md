- (i) **M4 のカンニングは相手の手札だけ。** 相手の山札順・自分の山札順は従来どおりエージェントの乱数で混ぜる。理由: 測りたいのは「相手の私的情報（手札）の推論を完璧にしたら最大どれだけ強くなるか」（第 2 集 §3.5.4）であり、山札順は偶然の隠れ情報で推論の対象ではない（第 2 集 §2.7.5 の区別）。
- (ii) **Elo 換算は Δ = 400·log₁₀(p/(1−p))**（p はカンニング版から見た勝率）。閾値の対応は **+20 Elo ↔ p = 0.529・+50 Elo ↔ p = 0.571**。**判定は点推定で行い**、95% 区間が閾値をまたぐときは「境界」と併記する。境界でも追試はしない——II-7（硬い制約フィルタ）はどの分岐でもやるので、境界が変えるのは II-8・II-9 を同じ便に入れるかどうかだけであり、それは便 C の引継ぎ書で決められる。
- (iii) **W_t は「区別できる手札（多重集合）の数」**。公開情報は `_unseen`（相手のデッキリストから公開領域＝協奏・トラッシュ・アクションエリアを引いた未公開プール）と手札枚数、**それにスキャンで見て今も手札に残っている札（`observe` の `hand_known`）**。`hand_known` を必ず含む多重集合だけを数える。多重度で重みづけた分布のエントロピー H_w（配りが一様なら手札 h の確率 ∝ 多重度）も併記する（W と H_w の 2 列。本文の判定は D_t = 1 − log W_t / log W_0 で行う）。**相手のキャラの伏せ札は数えない**（本便の対象は手札）。
- (iv) **中盤 = その局の総ターン数 T の ⌈T/2⌉ ターン目**における、AI の最初の決定時の D_t。局ごとに 1 値を取り、200 局の中央値と四分位を書く。閾値 0.3 は Furtak & Buro の値（第 2 集 §2.7.4）。**この定義は回す前に固定し、後から動かさない。**
- (v) **lc の翻訳**: 決着した局の**最後の対抗**について、後知恵（真の手札）の詰み表（AI の合法提出 × 相手の合法提出）を作り、**全セルの勝敗結果（AI 勝ち／相手勝ち／未決着）が同じ**なら「相関している葉」。lc = 相関している局 ／ 対抗で決着した局。対抗以外で決着した局（進行不能など）は分母から外し、その数を書く。**「詰みがあったか」ではない**（詰みがあっても、相手の応手で結果が変わるなら相関していない）。
- (vi) **D1 の循環の規則**: 「k が k−1 に勝ち越している」は既知（V_4' 対 V_3 = 0.598 [0.570, 0.625]・G2 の固定 n）。そのうえで **k−2 対 k の勝率（k−2 から見て）の 95% 区間が 0.5 を含むか上回れば「循環あり」**、上端が 0.5 を下回れば「循環なし」。V_1 対 V_3 も同じ規則（V_3 対 V_2 = 0.547 [0.519, 0.575]・D-064 が k 対 k−1）。**2 世代のうち 1 つでも循環ありなら「循環あり」として便 E 7' に磁石を入れる**。
- (vii) **M4 は両側 Python で回す**（M7 と同じ）。カンニング版は Python でしか作れず、Rust と Python を混ぜた対局は無い。所要は champion ミラー 6.8 秒/局（Python・D065_NOTES）から **n=1,200 で約 70 分（workers=2）**。1 時間を超えるので D-072 により Kaggle が整っていれば Kaggle、整っていなければ作業環境で `--budget-sec 480` の塊（約 9 回の再開）で回す。

### 3.1 M5・M1（`experiments/diag_pimc.py`・1 日・Python・200 局）

**何を作るか**
