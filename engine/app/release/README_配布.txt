MeichoSim（非公式のファンツール）

■ 使い方
1. この zip を好きな場所に展開する（OneDrive などの同期フォルダの中は避ける）。
2. MeichoSim フォルダの中の MeichoSim.exe をダブルクリックする。
   初回は Windows の保護画面が出ることがある。「詳細情報」→「実行」で進む。
3. 黒いウィンドウが開き、しばらくするとブラウザに画面が出る。出ないときは、ブラウザで
   http://127.0.0.1:8765/ を開く。
4. やめるときは、黒いウィンドウを閉じる。

■ 自動更新
起動のたびに新しい版があるか確かめ、あれば自動で取り込んでから起動します。操作は要りません。
インターネットに繋がっていないときは、手元の版でそのまま起動します。
新しい版がうまく起動しなかったときは、自動で一つ前の版に戻ります。
いまの版と更新の履歴は、画面の「設定」で見られます。
画面に「新しい起動役が必要」と出たときは、配布者から新しい zip をもらってください。

■ フォルダの中身
MeichoSim.exe・_internal   起動役（Python 本体など）。触らない
contents                   アプリの中身。自動更新で入れ替わる。触らない
data                       あなたの対局の記録。消さない限り残る。新しい zip に入れ替えるときは、このフォルダを移せば引き継げる
launcher.json              更新元の設定

■ 困ったとき
・「ポート 8765 を別のプログラムが使っている」と出る → すでに MeichoSim が動いていないか確かめる。
・起動しなくなった → zip を展開し直す（data フォルダは残してよい）。
