## 2. このチャットで決めたことと理由（本文は APP-012〜014）

- **Origin の検査は「許すサイトを起動のたびに書く」形にした。**トンネルは TLS を終えて 127.0.0.1 へつなぐので、サーバは自分の外向きの名前を知らない。Quick Tunnel は URL が毎回変わるので焼き込めない
- **Host が IP か `localhost` なら通す。**付け替え（DNS rebinding）ができない名前なので、LAN のスマホから `http://<PC の IP>:8765/` で開く使い方を設定なしで残せる
- **Origin を付けない要求は通す。**起動役・自動クライアントはブラウザでない。別のサイトのページから操れるのはブラウザだけで、ブラウザは必ず Origin を付ける
- **`--allow-origin` を書いた起動は CPU 対戦を出さない**（`decide_cpu`）。直しである: トンネルは 127.0.0.1 へつなぐので、`--host` だけの判定では外から CPU 対戦が使えてしまうところだった
- トンネル用の起動は**開発ツリーから**（`python -m app.server --data … --allow-origin <URL>`）。起動役に口は足していない（`LAUNCHER_API` 1 のまま）
- **画像はアプリに入れない。**遊ぶ人が自分の端末で選び、その端末の IndexedDB（`meichosim.images`）にだけ入る。相手の画面の画像は相手が読み込んだもの。対応づけはファイル名の先頭の番号（デッキメーカーと同じ正規表現）
- **盤面の文字の要素は消さずに隠すだけ**（`.card.has-art`）。読み上げ・自動検査・拡大がそのまま使えるため
- **デッキメーカーのカードの一覧はアプリが持つ**（`/api/cards`）。遊べるのはエンジンが持つ番号だけ。公式の欄は手元の `cards_structured.json` から**重ねる**（localStorage `meichosim.deckmaker.cards`）。数値・種類・専用・名前はエンジンが正、特徴と効果は丸ごと入れ替える
- **デッキの置き場はロビーと 1 つ**（localStorage `meichosim.decks`、decklists と同じ形＋ `id`・`description`・`art`）。二重に持つと食い違うので。空の作りかけはロビーに出さない
- マスターの指示「デッキメーカーは既存のアーティファクトと同じ仕様、UI でよい」に従い、アーティファクト版のコードを `static/deck.html`・`static/css/deck.css`・`static/js/deck.js` に写した。変えたのは 4 点だけ（APP-014 の本文）

## 3. 却下した案・撤回した結論（再提案しない）

- **トンネルの外向きの名前をサーバが Host ヘッダから自動で信じる**（同じ場所なら通す）→ 採らなかった。DNS の付け替えで破られる。名前の付く Host は許すサイトに書いたものだけ
- **（撤回）機内モードの試しを 10 秒にする** → 40 秒に直した。サーバが切断に気づくのは応答が 20 秒ほど途絶えたあと（aiohttp の heartbeat=20）。短いと切れたことにならない
- **（撤回）スマホの切断中にスマホ側に「つなぎ直している」が必ず出る、と依頼書に書きかけた** → PC 側の「<名前> が切断中」の帯を見る形に直した。スマホ側の帯は一瞬しか出ないことがある
- **画像を盤面に出すとき、協奏エリアの横向きのカードで名前とコストの帯を消す** → 残した。重ねると上の細い帯しか見えない
- **画像を読み込むときに縮めて保管する** → 作らなかった。アーティファクト版と同じ方式（原寸の Blob）にするため。重さはマスターの実物で問題が出ていない
- **デッキメーカーを app.css の書式に作り直す** → 作らなかった（マスターの指示: アーティファクトと同じ UI）。別の書式 `deck.css` を持つ
- **デッキメーカーの字体を Google Fonts から取る** → 外した。配るファイルが外の配信元に頼らない（`test_pages_carry_no_official_assets_and_say_unofficial` がページ中の `http` を禁じる）
- 前の引継ぎ書 §3 の却下案（Render・Oracle・GitHub Pages・合言葉を目録で配り直す など）はそのまま有効

## 4. 落とし穴（前の引継ぎ書 §4 に足す分）

- **Windows では `localhost` が IPv6 の `::1` に行くことがある。**cloudflared には `--url http://127.0.0.1:8765` と書く（サーバは 127.0.0.1 でしか待っていない）。依頼書にもそう書いた
- **招待リンクは開いたページの URL から作られる**（`location.origin`）。トンネル越しに遊ぶときは PC のブラウザもトンネルの URL で開く
- **Playwright の `request` には `blob:` の読み出しも出る。**「画像を送っていない」を確かめるときは `blob:` を除いてから数える
- **Python の文字列置換で `.js`・`.css` を書き換えるとき、改行コードに気をつける。**`engine/app/` の文書（`.md`）は CRLF、コード（`.py`・`.js`・`.css`・`.html`）は LF。今回は `open(...,"rb")` で文書を扱い、コードはテキストで扱った。書き戻す前に `file` で確かめる
- **相手の送り箱はチャットの途中で増える**（今回も依頼書を書く途中で TA-9 が届いた）。エンジンが `meicho/engine.py`・`state.py`・`encode.py`・`greedy.py` を直したので、作業環境の `meicho/` を取り直して全検査を回し直した
- **作業環境は消える。**今回 99 件が回った組: 前の引継ぎ書 §4 の組 ＋ `engine/app/static/js/art.js`・`deck.js`・`static/deck.html`・`static/css/deck.css`（`engine/app/` の全部を取ればよい）＋ 新しい `meicho/*.py`。
  入れ直すもの: `pip install --break-system-packages pytest pytest-asyncio aiohttp numpy`。画面写しの道具に Pillow（入っていた）
- `PC_REQUEST_20260922_APP.md`（朝の Cloudflare の依頼書）と `PC_REQUEST_20260922b_APP.md`（トンネルの依頼書）は、どちらも**済**。やり直す必要は無い
