## 2. 何を打つか（上から 1 行ずつ）

### 2.1 書き戻しが載っているかと、検査（窓 1・A）

### 2.2 cloudflared を入れる（窓 2）

    winget install --id Cloudflare.cloudflared

入ったら**窓 2 を閉じて開き直し**（入れた道具の場所を cmd が知るのは開き直したあと）、

### 2.3 トンネルを立てる（窓 2）

    cloudflared tunnel --url http://127.0.0.1:8765

**`localhost` ではなく `127.0.0.1` と書く**（Windows では `localhost` が IPv6 の `::1` に行くことがあり、サーバは `127.0.0.1` でしか待っていないので、つながらない）。
しばらくすると、四角い枠の中に `https://<英単語をつないだ名前>.trycloudflare.com` が出る。**この URL を控える**（以下 `<トンネルの URL>` と書く）。窓 2 はこのまま開けておく。

### 2.4 サーバを立てる（窓 1・A）

    py -3.11 -m app.server --data C:\meicho_dist\tunnel_data --allow-origin <トンネルの URL>

`<トンネルの URL>` は 2.3 で控えたものに置き換える（`https://` から `.trycloudflare.com` まで。末尾の `/` は付けても付けなくてもよい）。**`--host` は付けない。**窓 1 もこのまま開けておく。

### 2.5 PC のブラウザで部屋を作る

1. PC のブラウザで **`<トンネルの URL>` を開く**（`http://127.0.0.1:8765/` ではない。招待リンクは開いたページの URL から作られるので、手元の名前で開くとスマホが入れないリンクになる）
2. 表示名を入れ、合言葉を決めて「部屋を作る」
3. 「招待」の「リンクをコピー」を押し、そのリンクを自分のスマホへ送る（LINE の自分用のトーク・メールなど、何でもよい）
4. 席に着き、デッキを選んで準備完了にする

### 2.6 スマホで入る

1. スマホの Wi-Fi を切る（モバイル回線だけにする）
2. 届いた招待リンクを開く → 表示名と合言葉を入れて「入室する」
3. もう 1 つの席に着き、デッキを選んで準備完了 → 対局が始まる

### 2.7 打ちながら、途中で 2 つ試す

1 局を最後まで打つ。途中の、どちらかの手番を待っている間に:

- **スマホの切断**: スマホを機内モードにして **40 秒ほど**待ち、機内モードを切る（サーバが切断に気づくのは、応答が 20 秒ほど途絶えたあと。短いと、切れたことにならないまま戻ってしまい、試しにならない）
- **PC の読み込み直し**: PC のブラウザで F5 を押す

最後まで打ったら、窓 1 と窓 2 でそれぞれ **Ctrl+C** を押して止める（トンネルの URL はそこで使えなくなる。次に立てると別の URL になる）。

## 5. 転びやすいところと症状

- `winget` が「認識されていません」→ winget が無い古い Windows。https://github.com/cloudflare/cloudflared/releases の最新版から `cloudflared-windows-amd64.exe` を落とし、`cloudflared.exe` に名前を変えて、その exe があるフォルダで窓 2 を開いて同じ行を打つ
- `cloudflared` が「認識されていません」（winget のあと）→ 窓 2 を開き直していない。開き直す
- 2.3 で `failed to request quick Tunnel` のような英語で止まる → Cloudflare 側の一時的な失敗のことがある。1 分待ってもう一度打つ
- 2.3 で `~/.cloudflared/config.yml` のような語を含む英語で止まる → 以前に Cloudflare Tunnel の設定を作ったことがあると Quick Tunnel は動かない。窓の文を貼ってほしい
- トンネルの URL を開くと `502 Bad Gateway` や `Unable to reach the origin service` → サーバ（窓 1）が立っていないか、2.3 で `localhost` と書いた。窓 1 を確かめ、2.3 を `127.0.0.1` でやり直す（URL が変わるので 2.4 も立て直す）
- トンネルの URL を開くと「知らない名前（…）で届いたので断った。」→ 2.4 の `--allow-origin` が抜けたか、URL を写し間違えた。窓 1 で Ctrl+C → 文の中に出た `--allow-origin …` の行どおりに立て直す
- 部屋を作ろうとすると「許していないページ（…）からの要求なので断った。」→ 上と同じ
- 2.4 で「サイトの形が読めない」「https://名前 の形で書く」→ URL に余計なもの（`/?room=` など）が付いている。`https://….trycloudflare.com` までにする
- 2.4 で `address already in use` のような英語 → 8765 番を別のもの（exe の黒い窓・前に立てたサーバ）が使っている。閉じてからもう一度
- スマホが「つなぎ直している」のまま戻らない／入室したのに盤面が出ない → WebSocket がトンネルを通っていない恐れ（**ここがいちばんあやしい**）。窓 1 と窓 2 の最後の 20 行ほどを貼ってほしい
- Windows の「ファイアウォールでブロックされています」の画面が出る → cloudflared は外へつなぎに行くだけなので、「キャンセル」でも動く見込み。動かなければ「アクセスを許可する」にしてもう一度
- 文字化け → 動作には影響しない。化けた行があれば知らせてほしい

うまくいかないときは、窓に出た文をそのまま貼ってもらえれば足りる。**合言葉（部屋の合言葉）は貼らない。**トンネルの URL は貼ってよい（Ctrl+C で止めたあとは使えない）。
