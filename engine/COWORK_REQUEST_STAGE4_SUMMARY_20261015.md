## これまでの要点（クラウドの Claude Code のまとめ・判定ではない読み方を含む）

### 物差し（D-170）

- 判定は直接の得点（挑戦の A 席の得点 − 0.5）。null は配線の確かめだけに使う
- 主比較は 2,800 局で、+3% を検出力 80% で見つけられる
- 判定の言葉は 4 つ
  - 下端 > 0 → 伸びた
  - 上端 < 0 → 悪くなった
  - 上端 < +0.02 → 区別できない（+2% 以上の改善は否定）
  - それ以外 → 区別できない（足し継ぐ）

### 汎用の出発点 G と、デッキ別の事前学習 S（すべて対象デッキ SANGE_RM のミラー・直接対決）

- 教材 0 局: G@0 は S@0 を大きく上回る（素 planner への得点で +0.23〜+0.35・D-157・物差しが違う）
- 教材 1,000 局: G-lr@1,000 − S@1,000 = +0.002 [−0.008, +0.012]（95%・8,400 局・D-175）
- 教材 3,000 局: G-lr − S@3,000 = −0.020 [−0.041, +0.001]（97.5%・2,800 局・D-173）
- 読み方: 汎用の出発点の優位は、教材 1,000 局までに消える

### 学び方 G-lr（汎用の V_0 から、対象デッキの netfree の教材 3,000 局を学習率 1e-4 で学ぶ）

### 物差しの教訓

- 区間を見ながら何度も足し継ぐと、「下端 > 0」が偶然でも出やすい。腕 C で実際に起きた
- 事前に大きさを決めて 1 回だけ測る確かめは、この偶然に強い
