## カード画像アセット（../cards/）

本ディレクトリ（`engine/`）の一つ上、`meicho_engine_v0.1/cards/` に、
公式サイト（wwcg.ucp-jp.com/jp/card）のカードデータベースから取得した
**全76件のカード画像**を格納している（取得日: 2026-08-31）。

- 形式: PNG（カード表面のみをトリミング済み）。ゲーム未リリースのため
  いずれも「SAMPLE」透かし入りのプレビュー版。
- 命名規則: `{カードコード}_{カード名}.png`（例: `SD01-001_漂泊者_女_LV2.png`）。
  レアリティ違いの再録カード（同一コードで★★版が別途存在するもの）は
  末尾に `-R` を付けて区別している（例: `BP01-003_ツバキ_LV1-R.png`）。
- カードの構造化データ（コスト・色・レベル・武器・カード効果テキスト等）は
  画像には含まれない。必要な場合はカードコードで公式サイトを再検索するか、
  `meicho/cards.py` の登録簿（テキストのみ、実装反映済みのカードに限る）を参照する。
- 用途: `CARD_INPUT_HANDOFF.md` のカードデータ入力作業や、対人検証アプリ
  （`webapp/`）でのカード表示素材としての利用を想定。エンジン本体（`meicho/`）は
  この画像フォルダに依存しない。
